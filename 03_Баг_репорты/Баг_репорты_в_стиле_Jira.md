# Баг-репорты в стиле Jira

## Issue: BUG-001
**Проект:** Wikipedia Mobile QA Project  
**Тип:** Bug  
**Краткое описание:** При переключении языка открывается некорректная языковая версия статьи  
**Статус:** Open  
**Приоритет:** High  
**Severity:** Major  
**Компонент:** Article / Language  
**Окружение:** Android 13  
**Автор:** Ваше Имя

**Описание:**  
При выборе другой языковой версии статьи приложение открывает некорректную локализацию.

**Шаги:**
1. Открыть статью
2. Перейти в меню выбора языка
3. Выбрать другой язык
4. Проверить открывшуюся статью

**Фактический результат:**  
Открывается статья не на выбранном языке.

**Ожидаемый результат:**  
Статья должна открываться на выбранном языке.

**Метки:** mobile, wikipedia, localization

**Тип:** Bug

**Приоритет:** High  
**Severity:** Major  
**Компонент:** Network / Article  
**Окружение:** Android 13, интернет отключен  
**Автор:** Ваше Имя

**Описание:**  
При открытии статьи без интернет-соединения приложение не показывает понятное сообщение пользователю.

**Шаги:**
1. Отключить интернет
2. Запустить приложение
3. Открыть статью

**Фактический результат:**

**Ожидаемый результат:**  
Должно отображаться понятное сообщение об отсутствии сети.

**Метки:** mobile, network, offline

**Приоритет:** Medium  
**Severity:** Medium

**Окружение:** Android 13  
**Автор:** Ваше Имя

1. Сохранить статью

3. Открыть приложение снова

**Ожидаемый результат:**

## Issue: BUG-005
**Проект:** Wikipedia Mobile QA Project  
**Тип:** Bug  
**Краткое описание:** При быстром переключении между статьями из поисковой выдачи иногда отображается предыдущий заголовок  
**Статус:** Open  
**Приоритет:** Medium  
**Severity:** Medium  
**Компонент:** Search / Article  
**Окружение:** Android 13  
**Автор:** Ваше Имя

**Описание:**  
При быстром открытии разных статей из результатов поиска на короткое время отображается предыдущий заголовок.

**Шаги:**
1. Выполнить поиск
2. Быстро открыть одну статью
3. Вернуться назад
4. Быстро открыть другую статью

**Фактический результат:**  
На короткое время отображается заголовок предыдущей статьи.

**Ожидаемый результат:**  
Должен сразу отображаться корректный заголовок текущей статьи.

**Метки:** search, article, ui
