# Учебный QA-проект: тестирование мобильного приложения Wikipedia Mobile

В данном репозитории представлен пример полного цикла ручного тестирования реального мобильного приложения **Wikipedia Mobile**.

## Цель проекта
Продемонстрировать практические навыки Junior QA Engineer / Manual Tester:
- анализ функциональности мобильного приложения;
- подготовка тестовой документации;
- ручное тестирование мобильного приложения;
- оформление баг-репортов;
- базовая проверка данных через публичный API;
- подготовка итоговой отчетности.

## Что протестировано
В рамках проекта были проверены следующие пользовательские сценарии:
- установка и первый запуск приложения;
- onboarding;
- поиск статей;
- открытие статьи;
- переходы по внутренним ссылкам;
- переключение языка статьи;
- сохранение статьи;
- история просмотров;
- share статьи;
- работа приложения без интернета;
- сохранение состояния после сворачивания;
- корректность отображения при смене ориентации устройства.

## Особенности проекта
Так как Wikipedia Mobile является реальным внешним продуктом, прямой доступ к внутренней базе данных отсутствует.  
Проверка данных выполняется через публичный **MediaWiki API**, что соответствует black-box подходу к тестированию внешнего приложения.

## Что демонстрирует проект
- умение анализировать мобильное приложение;
- навыки mobile testing;
- умение готовить тестовую документацию;
- навыки bug reporting;
- базовое API testing;
- умение валидировать данные через внешний API;
- аккуратную организацию QA-портфолио в GitHub.
