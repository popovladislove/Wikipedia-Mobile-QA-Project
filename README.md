# Учебный QA-проект: тестирование мобильного приложения Wikipedia Mobile

## Цель проекта
Тренировка практических навыков QA Engineer:
- анализ функциональности мобильного приложения;
- подготовка тестовой документации;
- ручное тестирование мобильного приложения;
- оформление баг-репортов;
- базовая проверка данных через публичный API;
- подготовка итоговой отчетности.

## Что протестировано
В рамках проекта были проверены следующие пользовательские сценарии:
- установка и первый запуск приложения;
- onboarding;
- поиск статей;
- открытие статьи;
- переходы по внутренним ссылкам;
- переключение языка статьи;
- сохранение статьи;
- история просмотров;
- share статьи;
- работа приложения без интернета;
- сохранение состояния после сворачивания;
- корректность отображения при смене ориентации устройства.
