# Учебный QA-проект: тестирование мобильного приложения Wikipedia Mobile

В данном репозитории представлен пример полного цикла ручного тестирования реального мобильного приложения **Wikipedia Mobile**.

## Цель проекта
Продемонстрировать практические навыки Junior QA Engineer / Manual Tester:
- анализ функциональности мобильного приложения;
- подготовка тестовой документации;
- ручное тестирование мобильного приложения;
- оформление баг-репортов;
- базовая проверка данных через публичный API;
- подготовка итоговой отчетности.

## Проверенные модули
- первый запуск приложения
- onboarding
- поиск статей
- открытие статьи
- переходы по внутренним ссылкам
- переключение языка статьи
- сохранение статьи
- история просмотров
- share статьи
- работа приложения без интернета
- сохранение состояния после background
- корректность отображения при смене ориентации

## Особенности проекта
Так как приложение является реальным внешним продуктом, проверка backend-данных выполняется через публичный **MediaWiki API**, а не через прямой доступ к базе данных.

## Структура репозитория
- `01_Описание_проекта` — описание приложения, источники требований, список модулей
- `02_Тестовая_документация` — тест-план, чек-листы, тест-кейсы, матрица трассировки, результаты прогона
- `03_Баг_репорты` — дефекты и их оформление в стиле Jira
- `04_API_тестирование` — API проверки и Postman
- `05_Проверка_данных` — валидация данных через API
- `06_Отчет_о_тестировании` — итоговая тестовая отчетность
- `07_Материалы_для_резюме` — готовые формулировки для резюме и собеседования
- `08_Google_Sheets_шаблоны` — заготовки для таблиц
