# Итоговый отчет о тестировании

## Проект
Wikipedia Mobile

## Тип проекта
Учебный QA-проект по тестированию реального мобильного приложения.

## Цель тестирования
Проверить основную функциональность мобильного приложения Wikipedia Mobile, подготовить комплект тестовой документации и продемонстрировать навыки ручного тестирования мобильного продукта.

## Проверенные модули
В рамках проекта были проверены следующие функциональные области:
- установка;
- запуск;
- onboarding;
- поиск;
- статья;
- навигация;
- языки;
- сохраненные статьи;
- история;
- share;
- сеть;
- background;
- ориентация;
- настройки.

## Выполненные работы
В рамках проекта были подготовлены и оформлены:
- описание проекта;
- тест-план;
- чек-лист;
- 28 тест-кейсов;
- матрица трассировки;
- результаты тестового прогона;
- 7 баг-репортов;
- API тест-кейсы;
- Postman collection;
- Postman environment;
- примеры request / response;
- документ по проверке данных через API.

## Статистика выполнения
- Всего тест-кейсов: 28
- Выполнено в рамках демонстрационного прогона: 11
- Passed: 8

- Not Run: 17

## Сводка по дефектам
- Всего дефектов: 7

### По severity:
- Major: 2
- Medium: 3
- Low: 2

## Основные найденные проблемы
1. Некорректное переключение языка статьи
2. Отсутствие понятного сообщения при отсутствии интернета
3. Нестабильная ошибка поиска без сети
4. Задержка отображения сохраненных статей
5. Кратковременное отображение предыдущего заголовка статьи
6. Визуальный скачок контента при смене ориентации
7. Смещение позиции скролла после share

## Использованные инструменты
- Manual Testing
- Mobile Testing
- Postman
- Google Sheets / Excel
- Markdown
- GitHub
- HTTP / JSON

## Особенности проекта
Так как Wikipedia Mobile является реальным внешним приложением:
- отсутствует доступ к внутренней БД;
- отсутствует доступ к исходному коду;
- данные валидируются через публичный MediaWiki API.

## Вывод
По результатам тестирования основные пользовательские сценарии приложения работают корректно, однако были обнаружены дефекты в следующих областях:
- локализация;
- обработка сетевых ошибок;
- работа с сохраненными статьями;
- стабильность пользовательского интерфейса.

Данный проект демонстрирует практические навыки Junior QA Engineer в области мобильного тестирования, тест-дизайна, bug reporting, API-проверок и оформления QA-артефактов в GitHub-портфолио.
