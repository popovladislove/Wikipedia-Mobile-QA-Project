# Тест-план

## Проект
Wikipedia Mobile

## Цель тестирования
Проверить основную функциональность мобильного приложения Wikipedia Mobile на уровне пользовательских сценариев и частично валидировать данные через публичный MediaWiki API.

## Scope

### Включено в тестирование
- установка и запуск приложения;
- onboarding;
- поиск статьи;
- открытие статьи;
- отображение заголовка и текста статьи;
- переходы по внутренним ссылкам;
- переключение языка статьи;
- сохранение статьи;
- отображение статьи в сохраненных;
- история просмотров;
- share статьи;
- работа приложения без интернета;
- сохранение состояния после сворачивания;
- поведение при смене ориентации устройства;
- базовые API-проверки поиска статьи, статьи по названию и языковых ссылок.

### Не включено в тестирование
- performance testing;
- security testing;
- автоматизация тестирования;
- полное тестирование accessibility;
- кросс-девайс тестирование на широком наборе устройств;
- глубокое тестирование внутренней архитектуры приложения.

## Типы тестирования
- функциональное тестирование;
- smoke testing;
- regression testing;
- UI testing;
- mobile testing;
- API testing;
- позитивное тестирование;
- негативное тестирование.

## Тестовое окружение
- мобильное устройство Android / эмулятор Android;
- интернет-соединение;
- Postman;
- Google Sheets / Excel;
- GitHub.

## Основные тестируемые модули
1. Установка
2. Запуск
3. Onboarding
4. Поиск
5. Статья
6. Навигация
7. Языки
8. Сохраненные статьи
9. История
10. Share
11. Сеть
12. Background
13. Ориентация
14. Настройки

## Ключевые риски
- нестабильное поведение приложения при отсутствии сети;
- различия в отображении на разных устройствах и версиях ОС;
- изменения в публичном API;
- отсутствие доступа к внутренней базе данных и исходному коду.

## Критерии начала тестирования
- приложение установлено;
- устройство готово к тестированию;
- имеется стабильное интернет-соединение для online-сценариев;
- подготовлен Postman для API-проверок;
- подготовлена тестовая документация.

## Критерии завершения тестирования
- выполнены сценарии высокого приоритета;
- оформлены найденные дефекты;
- подготовлены тест-кейсы, чек-листы и результаты прогона;
- подготовлен итоговый отчет о тестировании.

## Тестовые артефакты
По результатам проекта подготавливаются:
- описание проекта;
- тест-план;
- чек-лист;
- тест-кейсы;
- матрица трассировки;
- результаты прогона;
- баг-репорты;
- API тест-кейсы;
- Postman collection;
- описание валидации через API;
- итоговый отчет.
