# Проверка данных через публичный API

Так как у Wikipedia Mobile нет доступа к внутренней базе данных приложения для внешнего тестировщика, валидация данных выполняется через публичный API.

## Почему используется такой подход
В рамках black-box тестирования внешнего мобильного приложения у тестировщика нет возможности:
- выполнять SQL-запросы к внутренней БД продукта;
- смотреть серверные логи;
- анализировать внутренние структуры хранения данных.

Поэтому для проверки корректности отображаемой информации используется публичный **MediaWiki API**.

## Что проверяется через API
1. Наличие статьи в базе знаний Wikipedia
2. Наличие результатов поиска по запросу
3. Наличие альтернативных языковых версий статьи
4. Корректность ответа API при невалидных запросах
5. Доступность API и корректная структура ответов

## Для чего это нужно
Это позволяет проверить, что:
- UI отображает реальные данные;
- приложение получает корректную информацию со стороны сервера;
- логика поиска и отображения статьи соответствует backend-данным;
- найденные проблемы действительно относятся к мобильному клиенту, а не к отсутствию самих данных.
