# Источники требований

Для подготовки учебного QA-проекта по Wikipedia Mobile использовались следующие источники:

## 1. Описание приложения в Google Play / App Store
Использовалось как публичное описание ожидаемого поведения приложения и его основных возможностей.

## 2. Публичная документация MediaWiki API
Использовалась для:
- проверки существования статей;
- проверки поисковой выдачи;
- проверки языковых версий статьи;
- валидации данных, которые отображаются в приложении.

## 3. Публичные материалы экосистемы Wikimedia
Дополнительный источник понимания структуры контента и работы со статьями.

## 4. Анализ типовых пользовательских сценариев
Для составления тест-кейсов были выделены стандартные сценарии пользователя:
- поиск статьи;
- открытие статьи;
- переход по ссылкам;
- смена языка;
- сохранение статьи;
- работа без интернета;
- повторный запуск приложения.

## Важная особенность
Так как внутренняя проектная документация недоступна, требования в рамках данного учебного проекта были сформированы на основе:
- публично доступной информации;
- анализа продукта;
- пользовательских сценариев;
- black-box подхода к тестированию.
