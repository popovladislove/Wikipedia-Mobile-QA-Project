# Описание проекта: Wikipedia Mobile

## Тип приложения
Wikipedia Mobile — мобильное приложение для поиска, чтения и сохранения статей из Wikipedia.

## Платформы
- Android
- iOS

## Тип тестирования
Ручное тестирование мобильного приложения с дополнительной проверкой данных через публичный API.

## Цель тестирования
Проверить корректность работы основных пользовательских сценариев в мобильном приложении Wikipedia Mobile и подготовить набор тестовых артефактов

## Основной функционал приложения
- первый запуск приложения;
- onboarding;
- поиск статей;
- открытие статьи;
- переходы по внутренним ссылкам статьи;
- выбор языковой версии статьи;
- сохранение статьи;
- просмотр сохраненных статей;
- история просмотров;
- share статьи;
- работа при отсутствии сети;
- сохранение состояния после сворачивания;
- корректность отображения при смене ориентации устройства.

## Основные проверяемые модули
1. Установка
2. Запуск
3. Onboarding
4. Поиск
5. Статья
6. Навигация
7. Языки

14. Настройки

## Подход к тестированию
Так как приложение является внешним реальным продуктом, тестирование проводилось как black-box testing:
- без доступа к исходному коду;
- без доступа к внутренней базе данных;
- с опорой на пользовательские сценарии, фактическое поведение приложения и публичную документацию MediaWiki API.
